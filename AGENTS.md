# Contribution rules

Use the pinned Mathlib objects and search for existing declarations first.
Keep changes focused and disclose AI use in pull requests. State precisely what
was built and reviewed; do not claim expert human review or Palomar registration.
Do not add sorry, axioms, native_decide, or weaken statements to obtain a proof.
Do not commit credentials, account records, machine configuration, or raw agent
transcripts. Respect existing copyright and cite adapted source material.

For this maintainer's workflow, all Lean execution belongs on the authorized
WSL worker machine; the Mac is an editor/controller only. Build with bounded
resources and preserve verification receipts. Never upload private workspaces.
